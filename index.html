Vocabulary Quiz Maker

Upload a word list, shuffle the Chinese meanings, and save the quiz sheet and answer key as pictures.

1. Word list file

Tap to choose a file .xlsx, .exl or .csv, for example from the Files app. Words with green cells are the ones used (Excel files only)

Showing sample words. Upload your file to replace them.

2. Quiz settings

One line for each test type. Write the levels after a colon, separated by commas. Example: STYLE: L1, L2, L3. A line without a colon has no levels (example: PET).

Leave empty to use all words.

Pictures ready

Each button makes one picture (JPG) for every page and opens the iPhone share sheet. Tap Save Image (goes to Photos) or Save to Files. To use both, run the share sheet twice. Both sheets use the same numbers, order and page breaks.

3. Email

Makes the pictures of both sheets and opens the share sheet. Choose Gmail or Mail there.
